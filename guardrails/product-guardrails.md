# NepaliGarage — Product Guardrails

These are hard rules. They do not change without a documented decision. Any Claude session, developer, or AI agent working on this project must follow them.

---

## 1. Data Integrity Rules

**Every data point on the public site must have:**
- A value
- A source (URL, brochure name, or "NepaliGarage estimate")
- A confidence level: `official` | `estimated` | `unverified`
- A last-verified date

**Never display:**
- Spec values without a source label
- Prices without a confidence label (official vs. estimated)
- AI-generated spec data that hasn't been human-verified

**Confidence color codes:**
- Green badge = Official confirmed source
- Amber badge = Calculated estimate (formula must be documented)
- Red badge = Community-reported / unverified

---

## 2. AI Assistant Safety Rules

The AI assistant must classify every repair/maintenance query before responding:

| Risk Level | Examples | AI Behavior |
|------------|----------|-------------|
| Low | Wipers, cabin filter, tyre pressure, washer fluid, bulbs | Explain fully, give steps |
| Medium | Spark plugs, brake pads (visual check), battery terminal | Explain causes, recommend mechanic inspection |
| High | Brakes (replacement), airbags, suspension, steering, fuel system | Do NOT give DIY steps. Direct to certified mechanic. |
| EV High-Voltage | Battery pack, inverter, motor, charging system | Never DIY. Authorized EV technician only. Mandatory warning. |

**The AI must never:**
- Invent part numbers
- Confirm a part is compatible without a verified source
- Give a resale value without stating it is an estimate and the formula used
- Pretend to know Nepal-specific data it was not trained on or has no record of

---

## 3. Content Rules

**Never publish:**
- Comparison articles with unmatched rows (car A has a value, car B says "N/A" with no explanation)
- "Expected price" articles without showing the customs duty formula
- Copied brochure specs without Nepal-specific context
- AI-written articles that contain no Nepal-specific data
- Autoplay videos
- Slideshows that break data across 10 pages for ad impressions
- "Best car" articles that don't disclose sponsored relationships

**Always publish with:**
- Source citations per data field
- Date of last verification
- Nepal-specific context (road suitability, tax, service network, parts availability)
- Clear label if content is sponsored

---

## 4. Architecture Rules

**WordPress is for:**
- Public-facing pages and articles
- SEO content
- Rendering comparison pages (data fetched from Supabase)
- Blog posts and news

**Supabase is for:**
- All structured vehicle data (brands, models, variants, specs, prices)
- All user data (accounts, vehicle logs, documents, subscriptions)
- AI conversation history and vehicle memory
- Audit logs
- Parts and garage directory

**Never:**
- Store user vehicle records in WordPress
- Store structured spec data only in WordPress (it must be in Supabase)
- Use WordPress for user authentication for the dashboard (use Supabase Auth)

---

## 5. Monetization Ethics Rules

- Sponsored content must be labeled "Sponsored" visibly
- Dealer leads must be disclosed as a revenue model in the site's About page
- AI repair advice must never be sold as a substitute for professional diagnosis
- Inspection reports must be performed by a verified mechanic, not generated by AI alone
- Resale value estimates must state they are estimates with the formula, not official valuations

---

## 6. Build Sequence Rules

**Do not build Phase 2 features during Phase 1.**

| Phase | What gets built | What does NOT get built yet |
|-------|----------------|----------------------------|
| Phase 1 | Comparison engine, price estimator, vehicle database, admin panel | User accounts, AI assistant, parts marketplace |
| Phase 2 | User login, vehicle dashboard, service/fuel logs, documents, reminders | AI assistant, parts marketplace |
| Phase 3 | AI vehicle assistant on top of Phase 1 + Phase 2 data | Parts marketplace, fleet tools |
| Phase 4 | Parts finder, garage directory, vendor backend | Resale report generator |
| Phase 5 | Resale reports, inspection marketplace, fleet/workshop tools | — |

**Rationale:** AI assistant requires structured data to be useful. Parts finder requires vendor relationships. Resale reports require historical data. Skipping phases creates a product with no foundation.

---

## 7. What We Will Never Copy

- Slideshow articles (data split for ad impressions)
- Fake urgency ("Only 3 cars left at this price!")
- Comparison tables where rows are mismatched between cars
- SEO spam: keyword-stuffed articles with no real insight
- Review scores without explanation of methodology
- "Best car" lists driven by affiliate commission without disclosure
