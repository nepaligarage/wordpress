## 3. Brand Colors — CONFIRMED

The NepaliGarage palette is built on three core colors: **Nepali Red, Deep Blue, and White**. Every UI element uses gradients and combinations of these three.

### Core Colors

| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Nepali Red | `#C1121F` | CTA buttons, primary headings, badges, active states |
| Secondary | Deep Blue | `#1B2A6B` | Navigation, footer, section backgrounds, data tables |
| Base | Pure White | `#FFFFFF` | Page backgrounds, card backgrounds, text on dark |
| Off-White | Snow White | `#F8F9FA` | Alternating row backgrounds, input fields |

### Gradient System

| Gradient | Colors | Use |
|----------|--------|-----|
| Hero gradient | White → Light Blue `#E8F0FE` → `#1B2A6B` | Hero sections, landing page |
| CTA gradient | `#C1121F` → `#8B0000` | Primary buttons, urgency elements |
| Card accent | `#1B2A6B` → `#2563EB` | Feature cards, section headers |
| Flag-inspired | `#C1121F` → `#FFFFFF` → `#1B2A6B` | Brand banners, comparison headers |
| Subtle page | `#FFFFFF` → `#F0F4FF` | Page section dividers |

### Functional Colors (data confidence system)

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Confirmed data | Forest Green | `#16A34A` | Official source badge |
| Estimated data | Amber | `#D97706` | Calculated/estimated badge |
| Unverified | Soft Red | `#DC2626` | Community-reported badge |
| Neutral | Cool Gray | `#6B7280` | Secondary text, metadata |

### Color Rules
- Never use red and blue at equal weight without white as a separator
- Gradient direction: always light-to-dark or white-to-color (never dark-to-light on hero)
- Text on red backgrounds: always white
- Text on blue backgrounds: always white
- Text on white backgrounds: `#1B2A6B` (Deep Blue) for headings, `#374151` for body

## 4. Typography

| Role | Font | Source |
|------|------|--------|
| Headings | Inter (700, 800) | Google Fonts — free |
| Body | Inter (400, 500) | Google Fonts — free |
| Data / spec values | IBM Plex Mono | Google Fonts — free |
| Nepali script | Noto Sans Devanagari | Google Fonts — free |

**Why Inter:** Clean, modern, highly legible at small sizes for data tables. Pairs well with Devanagari fonts for bilingual content.

**Why IBM Plex Mono:** Spec values (battery size, ground clearance, part numbers) are data — a monospace font signals precision and makes numbers scannable.

## 5. Logo Principles

**Designer brief:**
- Wordmark: "NepaliGarage" in Inter Bold
- Accent: A simple geometric mark — either a stylized "NG" monogram or a minimal vehicle silhouette (SUV/crossover shape to reflect Nepal's terrain preference)
- Color versions: Full color (red + blue on white), White (on red/blue backgrounds), Single black (print)
- Must work at 16×16px as a favicon
- No complex gradients in the logo mark itself — gradients only in backgrounds
- Feeling: trustworthy, technical, local — not a generic oil-drop or wrench
